# Prediction of milk production of dairy cows

Tiimiliikmed:
Oliver Toomer
Kristofer-Robin Tiits
Mio Cristopher Vahtra

Motivation:
The motivation behind this project is to improve dairy farm management and cow health monitoring. Accurate predictions of milk production allow farmers to make better management decisions, set clear performance targets, and perform genetic benchmarking. Additionally, it enables effective herd performance monitoring, such as estimating mineral excretion, which is crucial for sustainable dairy farming. 

Goal:
The main goal of this project is to build an accurate machine learning model to predict milk, fat, and protein yields. Specifically, the project aims to make these predictions at two key stages: before the lactation period starts (day-0 prediction) and during ongoing lactations (day-n prediction). This is achieved by utilizing historical data, genetic information (EBV), and test-day records.
